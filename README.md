# BIOS

Сайт-візитка Бориса «Bios» — графіті-райтера з Одеси.
Статика: HTML + CSS + трохи JavaScript, без збірки й залежностей.

Композиція, сітка й типографіка зроблені за референсом
https://www.studio-merge.com — світлий фон, величезний щільний заголовок,
нумеровані пункти в рядок, сірий колір для другорядного тексту.

## Структура

```
index.html            вся сторінка, шість блоків
css/style.css         стилі
js/i18n.js            УСІ ТЕКСТИ і список робіт — правити тут
js/app.js             сітка, перемикач мови, лайтбокс
images/works/         кадри робіт
content/facts.md      факти про Бориса з посиланнями на джерела
content/works.md      звідки взято кожен кадр
```

## Як щось виправити

**Текст** — у `js/i18n.js`. Там два словники: `uk` і `en`.
Знаходиш слово, міняєш в обох. В `index.html` лізти не треба.

**Роботи** — там же, внизу файлу, список `window.WORKS`.
Порядок у списку = порядок на сайті.
`size:'wide'` — широка плитка (пів рядка), `size:''` — звичайна (третина рядка).

**Кольори** — на початку `css/style.css`, блок `:root`.
`--bg` — фон, `--ink` — текст, `--dim` — сірий для другорядного.

## Шрифти

Усі безкоштовні, з Google Fonts, обидва мають кирилицю:

- **Inter** — увесь текст і заголовки. Найближчий безкоштовний аналог
  шрифта з референсу; ефект дає не гарнітура, а розмір і щільний трекінг
- **Playfair Display** — тільки логотип «Bios», жирна антиква для контрасту

## Локальний запуск

```
npx serve
```

## Що ще треба

Перед публікацією Борис має підтвердити факти й дати добро на кадри —
список у `content/facts.md`, розділ «Потребує підтвердження».

Окремо бракує: оригіналів кількох робіт у високій якості, портрета,
фото журналу Legacy й шопу «Вуличний». Деталі — у `content/works.md`.

Контакт для замовлень зараз веде в Instagram-директ. Коли Борис дасть
пошту або Telegram — поміняти посилання в `index.html` (двічі: у шапці
й у блоці «Замовити»).
